# Harambe Escape

Retro arcade belt-scroller. You are Harambe. Fight out of the Cincinnati Zoo, through the streets, and into the jungle.

```bash
npm install
npm run dev
```

Move with A/D or the stick, change lanes with W/S, punch with J, chest-pound with K, jump with Space. On a phone the stick, JUMP, ATK, and POW sit under the wide screen.
